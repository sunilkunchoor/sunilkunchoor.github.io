# **App Name**: Sunil Kunchoor - MLOps Portfolio

## Core Features:

- Hero Section: Display a brief intro, title and contact buttons for 'View Projects' and 'Contact Me'.
- About Me Section: Describe background and years of experience.
- Featured Projects: Showcase key MLOps projects with descriptions and technologies used in a bento grid layout.  This includes a project that contains prompt management using LLMs.
- Tech Stack Marquee: An infinite scrolling marquee showing skills: Azure, Databricks, Kubernetes, Docker, Terraform, MLflow, Python, OpenVINO, GitHub Actions.
- Animated Data Background: An animated background with subtle particles or grid to represent data.

## Style Guidelines:

- Background: Slate-900 (#202A37) for a dark engineering mode theme.
- Primary text: Slate-200 (#E2E8F0) for readability against the dark background.
- Accent 1: Electric Blue (#7DF9FF) to represent Azure. Use sparingly for highlights.
- Accent 2: Neon Purple (#9D00FF) to represent Databricks. Use sparingly for highlights.
- Font: 'Inter', a sans-serif font, known for its clean and modern look.
- Glassmorphism effects on cards to provide a frosted glass appearance. Also, use a sticky header for navigation.
- Use Framer Motion for reveal-on-scroll and hover effects to enhance user experience.
